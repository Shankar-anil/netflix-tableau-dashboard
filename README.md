## 🔍 Key Insights
* **Format Split:** Movies dominate the platform at **68.42%**, outnumbering TV Shows (**31.58%**).
* **Top Audience:** **TV-MA** is the most frequent rating, showing a strong focus on mature audiences.
* **Top Genres:** **Documentaries** and **Stand-Up Comedies** lead the catalog counts.

## 🛠️ Tools Used
* **Tableau** (Geographic mapping, bar charts, custom dark UI)
* **Dataset:** Netflix Titles `.csv` file
